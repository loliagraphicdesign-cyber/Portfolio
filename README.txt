تحديث موقع بورتفوليو لوليا

المحتويات:
- index.html: الصفحة الرئيسية المحدثة.
- assets/: صور صفحات المشاريع الثلاثة.

طريقة الرفع إلى GitHub:
1. افتحي مستودع Portfolio.
2. ارفعي ملف index.html الجديد إلى جذر المستودع واختاري Replace إذا طُلب.
3. ارفعي مجلد assets كاملًا مع المجلدات الفرعية enercon وcampaign وlolia. أسهل طريقة: من Add file > Upload files اسحبي مجلد assets كاملًا من جهازك. إذا لم يقبل المجلد، افتحي كل مجلد وارفعِي الصور مع الحفاظ على المسارات.
4. اضغطي Commit changes.
5. انتظري دقيقة أو دقيقتين ثم افتحي رابط GitHub Pages.

ملاحظة: الصور داخل PDFs المستخدمة هنا صفحات المشاريع كما وردت في الملفات، ولم أغيّر التصاميم الأصلية. بعض الصفحات فيها موكابات جاهزة، ويمكن استبدال أي صورة لاحقًا بصورة موكاب منفصلة بجودة أعلى.
